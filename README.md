# SAF Management

TypeScript web app for SAF management, built with Next.js and React.

## Stack

| Layer | Choice |
| --- | --- |
| Runtime | Node.js |
| Language | TypeScript |
| Framework | Next.js (App Router) |
| UI | React |
| Package manager | npm |

## Requirements

- Node.js (LTS)
- npm

## Setup

```bash
npm install
```

## Scripts

```bash
npm test
```

App start scripts (`dev`, `build`, `start`) will be added when the Next.js app is scaffolded.

## Project status

Early setup. The Next.js app is not in the repo yet. Current `package.json` has `dotenv` as the first dependency.
